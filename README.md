# hingeleaf

Hinge CSV/TSV leaf tables for quick inspection and cleanup.

**Site:** https://theworker02.github.io/hingeleaf/

## Install / run

```bash
git clone https://github.com/theworker02/hingeleaf.git
cd hingeleaf
node src/cli.js
node --test
```
